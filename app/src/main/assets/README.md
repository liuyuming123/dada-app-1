# 哒哒宝贝 - 幼儿互动乐园

## 📱 应用介绍

"哒哒宝贝"是一款专为幼儿设计的互动学习应用，包含四大功能模块：

- **问一问** - AI语音助手，小朋友可以和哒哒聊天、问问题
- **看一看** - 图片浏览，支持实景图、玩法图、作品图、设计图分类查看
- **画一画** - 涂鸦画板，支持多种颜色和画笔粗细调节
- **拍一拍** - 上传图片、语音输入、生成动画作品

## 🖥️ 屏幕适配

本应用已针对 **16:9 屏幕比例** 进行优化适配：

- 横屏设备：最大宽度为屏幕高度的 177.78%（16:9）
- 竖屏设备：最大高度为屏幕宽度的 177.78%（9:16）
- 支持响应式布局，自动适应不同屏幕尺寸

## 🚀 安装方法

### 方法一：PWA 安装（推荐）

1. 使用手机或平板浏览器访问应用链接
2. 点击浏览器菜单（通常是三个点）
3. 选择"添加到主屏幕"或"安装应用"
4. 按照提示完成安装

### 方法二：iOS Safari 安装

1. 使用 Safari 浏览器访问应用链接
2. 点击底部分享按钮
3. 选择"添加到主屏幕"
4. 点击"添加"完成安装

### 方法三：Android Chrome 安装

1. 使用 Chrome 浏览器访问应用链接
2. 点击右上角菜单（三个点）
3. 选择"安装应用"或"添加到主屏幕"
4. 点击"安装"完成

## 🎨 功能说明

### 问一问
- 支持语音识别输入
- AI 智能回复
- 支持图片搜索和展示
- 语音朗读功能

### 看一看
- 支持图片分类浏览
- 支持从本地数据库导入图片
- 支持图片上传和预览
- 支持图片删除管理

### 画一画
- 支持多种颜色选择
- 支持画笔粗细调节
- 支持撤销和清空
- 支持保存作品

### 拍一拍
- 支持图片上传
- 支持语音输入
- 支持 AI 动画生成
- 支持作品评价

## ⚙️ 技术特性

- **16:9 屏幕适配** - 针对幼儿平板设备优化
- **PWA 支持** - 可安装为原生应用
- **响应式设计** - 适配各种屏幕尺寸
- **触摸优化** - 针对触摸操作优化
- **离线缓存** - 支持离线使用（部分功能）

## 📋 系统要求

- 现代浏览器（Chrome、Safari、Edge、Firefox）
- 支持 JavaScript
- 支持 LocalStorage
- 推荐使用平板设备获得最佳体验

## 🔒 隐私说明

- 所有数据存储在本地设备
- 不会上传用户隐私信息
- 图片数据保存在浏览器本地存储
