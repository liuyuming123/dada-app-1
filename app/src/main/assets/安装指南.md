## 🎯 快速安装

### iPhone / iPad (Safari)

1. 打开 Safari 浏览器
2. 访问上面的链接
3. 点击底部分享按钮 ![分享图标]
4. 选择"**添加到主屏幕**"
5. 点击"**添加**"
6. 完成！从主屏幕打开即可

### Android 手机/平板 (Chrome)

1. 打开 Chrome 浏览器
2. 访问上面的链接
3. 点击右上角菜单（三个点）
4. 选择"**安装应用**"或"**添加到主屏幕**"
5. 点击"**安装**"
6. 完成！从主屏幕或应用列表打开

### 其他浏览器

- **Edge**: 菜单 → 应用 → 安装此站点作为应用
- **Firefox**: 菜单 → 添加到主屏幕
- **Samsung 浏览器**: 菜单 → 添加到主屏幕

## 🖥️ 屏幕适配说明

本应用已针对 **16:9 屏幕比例** 进行优化：

| 设备类型 | 适配方式 |
|---------|---------|
| 横屏平板 | 宽度 = 高度 × 1.778 |
| 竖屏平板 | 高度 = 宽度 × 1.778 |
| 普通手机 | 自动全屏适配 |

**推荐设备**: 10寸以上平板电脑，横屏使用体验最佳

## 🚀 本地运行

### 方法1：直接打开
双击 `index.html` 文件即可在浏览器中打开

### 方法2：本地服务器（推荐）
使用 Python 启动本地服务器：

```bash
# 进入项目目录
cd dada-app

# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

然后访问 `http://localhost:8080`

### 方法3：VS Code Live Server
1. 安装 VS Code
2. 安装 Live Server 插件
3. 右键点击 index.html → "Open with Live Server"

## ⚠️ 注意事项

1. **首次使用**: 建议允许麦克风权限，以便使用语音功能
2. **图片存储**: 上传的图片保存在浏览器本地，清除浏览器数据会丢失
3. **网络要求**: 问一问和拍一拍功能需要网络连接
4. **浏览器推荐**: Chrome、Safari、Edge 最新版本

## ❓ 常见问题

### Q: 为什么语音功能无法使用？
A: 请检查：
- 是否允许了麦克风权限
- 浏览器是否支持语音识别（Chrome/Edge/Safari 支持）
- 网络连接是否正常

### Q: 图片上传后在哪里查看？
A: 图片保存在浏览器本地存储中，可以在"看一看"页面查看

### Q: 如何备份我的图片？
A: 目前需要手动导出，建议定期备份浏览器数据或使用导出功能

### Q: 支持离线使用吗？
A: 部分功能支持离线使用（画一画、看一看已缓存的图片），但问一问和拍一拍需要网络
